# 🍕 PizzaDay NFT Minter 🍕

## Project Overview

This is a React-based frontend application for interacting with the "PizzaDay NFT" smart contract. It allows users to:

* Connect their Ethereum wallets (via RainbowKit, supporting MetaMask, WalletConnect, etc.).
* View collection information, including total supply and max supply.
* Mint a "PizzaDay NFT" (one mint per address is enforced by the smart contract).
* View their minted NFT, including its image (or a carousel of images if provided in metadata), name, description, and attributes.
* See a special congratulatory message if their minted NFT has a "Status" attribute of "Winner".

The application is built using React, Vite (assumed for `import.meta.env`), Wagmi for blockchain interactions, RainbowKit for wallet connections, and Tailwind CSS for styling.

## Features

* **Wallet Connection:** Seamless multi-wallet connection using RainbowKit.
* **NFT Minting:** Securely mint an NFT from the `PizzaDay` smart contract.
* **Supply Display:** Shows current minted supply vs. maximum supply.
* **"One Mint Per Address" Check:** UI reflects the contract rule.
* **NFT Display:**
    * Shows the minted NFT's image (or an image carousel if `metadata.images` is an array).
    * Displays token ID, name, description, and attributes.
    * Highlights "Winner" status.
* **Responsive Design:** Styled with Tailwind CSS for various screen sizes.
* **IPFS Integration:** Fetches metadata and images from IPFS via a configurable gateway.

## Prerequisites

Before you begin, ensure you have the following installed:

* [Node.js](https://nodejs.org/) (v18.x or v20.x recommended)
* [npm](https://www.npmjs.com/) (v9.x or v10.x recommended) or [yarn](https://yarnpkg.com/)
* [Git](https://git-scm.com/)

You will also need:

* A **WalletConnect Project ID**: Obtain this from [WalletConnect Cloud](https://cloud.walletconnect.com/).
* A **Base Mainnet RPC URL**: Get this from an RPC provider like Alchemy, Infura, QuickNode, etc. Public RPCs may lead to rate-limiting issues.

## Key Configuration Points in `App.jsx`

* **`CONTRACT_ADDRESS`**: Loaded from `VITE_CONTRACT_ADDRESS`.
* **`RAW_IPFS_GATEWAY_PREFIX`**: Loaded from `VITE_IPFS_GATEWAY_PREFIX`. The `convertIpfsUriToHttpUrl` function uses this to resolve `ipfs://` URIs.
* **`PIZZADAY_NFT_ABI`**: Currently parsed from a human-readable string array. For production, it's recommended to import the full JSON ABI from your contract artifacts.

## Smart Contract Interaction

The application interacts with the `PizzaDay` smart contract for:
* Fetching `MAX_SUPPLY` and `totalSupply`.
* Checking if an address `hasMinted`.
* Executing the `mintNFT` transaction.
* Fetching `balanceOf`, `tokenOfOwnerByIndex`, and `tokenURI` to display NFT details.

## Notes

* **Network:** The application is configured for **Base Mainnet**. Ensure your wallet is connected to this network when interacting with the DApp.
* **Error Handling:** Basic error handling and user feedback are implemented. This can be expanded for a more robust user experience.
* **IPFS Gateway:** Using a reliable IPFS gateway (either a public one like `ipfs.io` or a dedicated one like Pinata) is crucial for fetching metadata and images. The current `VITE_IPFS_GATEWAY_PREFIX` should be set to your preferred gateway.
* **ABI:** While `parseAbi` is used for convenience with human-readable strings, for production applications, it's best practice to use the full JSON ABI generated by your smart contract compilation process (e.g., from Hardhat artifacts). This provides better type safety and ensures all contract elements are correctly defined.
